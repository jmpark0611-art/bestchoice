# AI 이용 안내 (입력 화면 노출용)

- 입력한 고민과 답변은 AI 처리를 위해 외부 AI 서비스(OpenAI)로 전송됩니다.
- Responses API 요청은 저장 안 함(store:false)을 적용하고, 별도 동의가 없는 API 데이터는 모델 학습에 사용되지 않습니다. 다만 안전·남용 방지 로그에는 입력과 출력이 포함되어 기본 최대 30일 보관될 수 있습니다.
- 이름, 연락처, 주민번호, 계좌·건강 정보 등 민감한 개인정보는 입력하지 마세요.
- AI 결과는 판단을 돕는 참고 자료이며, 최종 결정은 본인이 합니다.
- 의료·법률·투자 등 중요한 결정은 전문가 확인을 함께 받으세요.
- 기록은 작성 후 2개월이 지나면 자동으로 삭제되며, 앱의 삭제 기능으로 언제든 지울 수 있습니다.
