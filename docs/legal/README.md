# 정책 문서 초안 (Bestchoice)

작성 기준일: 2026-09-29. **법률 자문이 아닌 구현 기준 초안**입니다. 출시 전 `[확정 필요]` 항목을 채우고 필요하면 전문가 검토를 받으세요.

## 코드/DB 확인으로 검증된 사실 (초안의 근거)
- 인증: Supabase 익명 로그인. 이름·전화번호·이메일 등을 수집하지 않음 (`bc_users`는 id, created_at만 보유).
- 저장 항목: 고민 원문(20~1,000자), 요약·분류, AI 확인 질문과 사용자 답변, AI 분석 결과, 실제 선택(유형+메모 300자), 이용 이벤트(`bc_analytics_events`: 이벤트명·시각).
- 국외 처리: Supabase(서울 리전, DB·인증·함수 실행), OpenAI(고민 원문·답변 전송, 요청에 `store:false` 지정 → 저장 옵션 미사용. 단 OpenAI 측 남용 모니터링 목적 보관 정책은 별도 확인 필요).
- 삭제: `bc_delete_my_decisions`로 본인 결정 전체 삭제, 하위 데이터는 FK cascade로 함께 삭제.
- **자동 보관기간 만료 삭제(cron 등)는 현재 없음.** 사용자가 삭제하기 전까지 보관됨.
- **삭제 후에도 `bc_decision_request_tombstones`(결정 id, 사용자 id)가 남음.** 중복 요청 방지용이며 고민 내용은 아니지만 방침에 명시하거나 삭제 로직 조정 필요.
- 계정(auth 사용자) 자체 삭제 기능은 확인되지 않음. `[확정 필요]`
