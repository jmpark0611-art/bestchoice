# 정책 문서 초안 (Bestchoice)

작성 기준일: 2026-10-04. **법률 자문이 아닌 구현 기준 초안**입니다. 출시 전 시행일을 채우고 필요하면 전문가 검토를 받으세요.

## 코드/DB 확인으로 검증된 사실 (초안의 근거)
- 인증: Supabase 익명 로그인. 이름·전화번호·이메일 등을 수집하지 않음 (`bc_users`는 id, created_at만 보유).
- 저장 항목: 고민 원문(20~1,000자), 요약·분류, AI 확인 질문과 사용자 답변, AI 분석 결과, 실제 선택(유형+메모 300자), 이용 이벤트(`bc_analytics_events`: 이벤트명·시각).
- 국외 처리: Supabase(서울 리전, DB·인증·함수 실행), OpenAI(고민 원문·답변 전송, 요청에 `store:false` 지정). OpenAI 공식 문서상 API 데이터는 별도 동의 없이 학습에 사용되지 않고, 안전·남용 방지 로그는 기본 최대 30일 보관될 수 있음.
- 삭제: `bc_delete_my_decisions`로 본인 결정 전체 삭제, 하위 데이터는 FK cascade로 함께 삭제.
- 보관기간: 작성 후 2개월 자동 삭제(pg_cron 매일 03:00 KST). tombstone도 2개월 후 삭제. (2026-09-29 결정·적용)
- 계정 삭제: 앱 내 버튼 → `bc_delete_account()` RPC로 계정과 모든 기록 즉시 삭제. (DB 적용 완료, 앱 버튼은 미구현)
- 시행일: 검수 요청일로 기입.
