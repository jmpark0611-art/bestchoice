## 2. 보유·이용 기간
- 고민 내용, 답변, AI 분석 결과, 실제 선택, 이용 이벤트는 **작성일로부터 2개월간 보관한 뒤 자동으로 파기**합니다.
- 보관기간 중이라도 사용자가 기록 삭제 또는 계정 삭제를 하면 즉시 파기합니다.
- 결정 삭제 후 중복 요청 방지를 위한 식별자(결정 ID, 계정 식별자)는 내용 없이 최대 2개월간 보관 후 파기합니다.

## 4. 국외 이전
AI 기능을 실행하면 고민 내용, 생성된 질문과 답변이 OpenAI, L.L.C.에 전송되어 미국을 포함한 OpenAI의 처리 시설에서 AI 응답 생성과 안전 관리를 위해 처리될 수 있습니다. 전송은 사용자가 질문 생성 또는 분석을 요청한 시점에 암호화된 네트워크로 이루어집니다. API 데이터는 사용자가 별도로 동의해 공유하지 않는 한 모델 학습에 사용되지 않습니다. 다만 입력·출력과 관련 메타데이터가 안전·남용 방지 로그에 포함되어 기본 최대 30일 보관될 수 있으며, 법적 의무 또는 서비스·제3자 보호에 필요한 경우 더 오래 보관될 수 있습니다. OpenAI의 최신 데이터 정책은 https://developers.openai.com/api/docs/guides/your-data 에서 확인할 수 있습니다.
