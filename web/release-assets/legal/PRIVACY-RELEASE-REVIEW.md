## 완료한 준비물

- `privacy.html`: 한국어 개인정보처리방침 검토본. 처리 항목·목적, AI 전달, 공유 범위, 기기 저장, 정보별 보관·삭제, 권리 행사 연락처를 작성했다.

- 상단에 게시 전 검토본임을 표시하고 검색 제외 메타데이터를 넣었다. 공개 주소·시행일은 만들지 않았다.

## 게시 시 사용할 수 있는 배치 계획

- 제안 경로는 **/privacy**, **/delete-data**다. 확정 URL이나 현재 동작하는 경로가 아니다.
- 원본 파일은 같은 폴더의 `privacy.html`, `delete-data.html`을 서로 상대 링크한다. 파일 경로 그대로 게시할 경우 상대 링크가 작동한다. 확장자 없는 경로로 게시하면 양방향 링크도 확정 경로로 바꾼다.
- 공개 호스팅은 계정 로그인·앱 설치·지역 제한 없이 HTML을 읽을 수 있게 설정한다. Play에는 확인된 실제 URL만 입력한다.
- 새 문서는 기존 빌드 산출물에 자동 포함되지 않는다. Vite public로 이동하거나 앱에 링크를 추가하는 작업은 별도 변경으로 기록한다.
- 실제 게시 후 본문 내용, 회사/앱 이름, 사용 가능한 이메일, 링크, 작은 화면 및 키보드 접근을 확인한다. 현재 검증은 정적 구조 검증이며 브라우저 실화면·메일 수신·공개 네트워크 확인은 수행하지 않았다.
- 인증 전체 삭제가 필요하다고 결정되면 이 안내문만으로 기능 완료로 처리하지 않는다. 앱 내·외 요청 경로와 서버 처리·소유 확인·결과 안내가 함께 있어야 한다.
