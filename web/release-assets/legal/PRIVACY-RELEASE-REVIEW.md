# 결정해지니 개인정보·삭제 안내 게시 검토

## 완료한 준비물

- `privacy.html`: 한국어 개인정보처리방침 검토본. 처리 항목·목적, AI 전달, 공유 범위, 기기 저장, 정보별 보관·삭제, 권리 행사 연락처를 작성했다.
- `delete-data.html`: 한국어 데이터 삭제 안내 검토본. 실제 앱 버튼을 따라가는 삭제 절차와 기기 정보 삭제, 최소정보로 보내는 이메일 문의 예시를 작성했다.
- `privacy-evidence.json`: 정확한 소스 기준, 확인된 동작, 적용 전 구조, 공식 정책 자료, 남은 확인 항목을 분리했다.
- 두 HTML은 UTF-8·한국어·반응형 단일 파일이다. 스크립트·입력 폼·쿠키·외부 폰트·분석 도구 없이 열린다. 실제 전송은 사용자가 메일 앱에서 보내는 경우에만 발생한다.
- 상단에 게시 전 검토본임을 표시하고 검색 제외 메타데이터를 넣었다. 공개 주소·시행일은 만들지 않았다.
- 2026-11-25 운영 승인 내용을 두 HTML과 앱 공통 본문 `web/src/legal/legalContent.ts`에 반영했다. 문의 담당 박지민, 최초 접수·분류 답변 1영업일 목표, 처리 종료 후 최소 처리표 최대 30일이라는 세 항목만 확정 사실로 추가했다.

이 문서는 게시 계획과 사실 확인 기록이다. **두 HTML을 그대로 정식 정책으로 게시하거나 Play의 개인정보처리방침 완료로 표시하면 안 된다.** 실제 보관·처리 조건이 아직 비어 있는 부분은 아래에 모았다. 사용자에게 회사명·대표·이메일·18세 이상 대상 여부를 다시 묻지 않는다.

## 게시 시 사용할 수 있는 배치 계획

- 외부 게시의 제안 경로는 **/privacy**, **/delete-data**다. 같은 이름의 앱 내 검토본 경로는 있지만, 이것이 공개 호스트의 실제 URL이나 외부 접속 확인을 뜻하지 않는다.
- 원본 파일은 같은 폴더의 `privacy.html`, `delete-data.html`을 서로 상대 링크한다. 파일 경로 그대로 게시할 경우 상대 링크가 작동한다. 확장자 없는 경로로 게시하면 양방향 링크도 확정 경로로 바꾼다.
- 공개 호스팅은 계정 로그인·앱 설치·지역 제한 없이 HTML을 읽을 수 있게 설정한다. Play에는 확인된 실제 URL만 입력한다.
- standalone HTML 원본은 Vite public 바깥에 있다. 앱에는 `legalContent.ts`의 별도 공통 본문이 포함되므로 두 문서의 내용을 함께 관리한다. 이번 텍스트 변경은 새 후보를 만들 때 포함되며 기존 서명 AAB는 바뀌지 않는다.
- 실제 게시 후 본문 내용, 회사/앱 이름, 사용 가능한 이메일, 링크, 작은 화면 및 키보드 접근을 확인한다. 현재 검증은 정적 구조 검증이며 브라우저 실화면·메일 수신·공개 네트워크 확인은 수행하지 않았다.
- 인증 전체 삭제가 필요하다고 결정되면 이 안내문만으로 기능 완료로 처리하지 않는다. 앱 내·외 요청 경로와 서버 처리·소유 확인·결과 안내가 함께 있어야 한다.
