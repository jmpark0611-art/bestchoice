## 공개 정책 문구에 반영하는 방법

- 이번에 확정한 설정값은 내부 근거에 보관한다. 공개 본문에 JWT 3600초나 UI 옵션 이름을 기술적으로 나열할 필요는 없다.
- 정책에는 **어떤 인증·접속 정보가 무슨 목적으로 얼마나 남는지와 어떻게 삭제를 요청하는지**를 적는다. 그 기간과 처리 절차가 확인되지 않은 부분은 설정값을 대입해 메우지 않는다.
- “감사 로그를 수집하지 않음”, “모든 백업 없음”, “1시간 뒤 사용자 정보 삭제” 문구는 사용하지 않는다.
- 정책 HTML 4개를 그대로 보존했다. 이번 갱신은 OpenAI의 로그인 필요 상태만 반영했다. 인증 선택 요청은 다른 자율 작업을 마친 뒤 루트가 문서화된 browserAuth 절차로 진행할 예정이며, 이 문서 작업에서는 자격 증명을 읽거나 입력하지 않았다. 실제 설정 조회 후 정책 최종화는 별도 검토된 변경으로 한다.
